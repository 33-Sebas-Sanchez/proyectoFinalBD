\section{Modelo de acceso}

El sistema aplica \textbf{control de acceso basado en roles} (RBAC) con los
mecanismos nativos de PostgreSQL. Cada microservicio es un esquema independiente
y los privilegios se conceden a nivel de esquema y de tabla:

\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
  \item Cada esquema tiene un \textbf{rol propietario} con privilegios plenos
        sobre sus tablas y secuencias.
  \item Los roles de negocio reciben \'unicamente los permisos necesarios para
        su funci\'on.
  \item El esquema \texttt{reportes} no posee tablas propias: solo vistas de
        lectura.
  \item El rol de auditor\'ia puede leer todos los esquemas, incluida la tabla
        \texttt{auditoria\_accesos}, sin modificar registros.
\end{itemize}

\section*{Nota de implementaci\'on}

Los privilegios se materializan con \texttt{GRANT USAGE ON SCHEMA} para habilitar
el acceso al esquema y con \texttt{GRANT SELECT, INSERT, UPDATE, DELETE ON ALL
TABLES} para los permisos de tabla. Las secuencias requieren adem\'as
\texttt{GRANT USAGE, SELECT ON ALL SEQUENCES}. La tabla de auditor\'ia se protege
revocando \texttt{UPDATE} y \texttt{DELETE} para todos los roles de negocio.
